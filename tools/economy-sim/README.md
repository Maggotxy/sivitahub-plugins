# 经济仿真器规格（v1）

> 目标：在不触及生产数据库与玩家资产的前提下，以真实配置为输入，验证经济闭环、兑换无套利、库存与产销比。

## 1. 输入（必须来自真实运行配置）

- `plugins/rpg-economy/src/main/resources/config.yml`：活动额度、日/周限、掉率
- `plugins/rpg-commerce/config.yml`：星辉商品成本与周限
- `plugins/rpg-core` 账本与兑换向量：`gold=1, merit=600, starlight=1400`
- 兑换表与费用：市场 5%/10%，委托劳作证明门槛

仿真启动时校验以上文件的 SHA 与加载值，参数不一致则直接失败，防止仿真私参漂移。

## 2. 玩家模型（10类）

| 模型 | 行为 |
|---|---|
| 新人休闲 | 1h/日，原版+狩猎，小额委托 |
| 周末玩家 | 周末集中，副本 2-3 次 |
| 核心玩家 | 3h/日，全活动近上限 |
| 硬核刷子 | 6h/日，冲单一最高收益 |
| 商人 | 低买高卖，提供流动性 |
| 锻造者 | 锻造→精炼→市场，消耗金币 |
| 社群组织者 | 组织周工程，分摊成本 |
| 休眠富豪回归 | 携存量金币/星辉回归，集中消费 |
| 小号 | 共享库存，试探委托套利 |
| 自动化恶意 | 高频、跨号对敲、资源脚本 |

每模型含：在线分布、活动偏好、价格弹性、风险偏好。

## 3. 输出指标

- 活跃金币周增长、总金币周增长
- 7日 Sink/Faucet、分来源/分回收口占比
- 转换释放金币占比
- 高价值装备 创建/退出比
- 市场挂牌 P50/P90/最老库存龄、7日成交/过期比
- 财富基尼与前1%份额
- 兑换图正价值环检测

## 4. 场景

见 `scenarios.v1.yaml`（15组），覆盖封闭测试、开荒至成熟、长期社区、收益集中、Faucet放大、富豪回归、垄断、内容真空、流动性枯竭、复制、集中发放、周末集中、小号共享、换季重放、support_credit误连接。

## 5. 证据要求

- 每次仿真输出 `simulation.json` 含输入 SHA、随机种子、指标、告警
- 与真实 7日快照对比，偏差 >阈值则标记 `NEEDS_TUNING`
- `support_credit` 误触游戏财富时仿真直接失败（对应场景15）
