# 旧 Particles 项目审计与迁移边界

审计对象为 <https://github.com/zypec/Particles>，本地只读快照位于 `cache/upstream/Particles`。核对提交为 `a79d384ee2e1fbd2f47284091953c9f5e99e364a`（2026-01-22），仓库共 423 次提交，默认 `effects.yml` 含 73 个效果。

## 结论

旧 JAR 不直接进入 Minecraft 26.2 运行服。视觉语言值得保留，但实现必须适配现服的公共 API、统一视觉优先级和性能预算。因此本服新增独立的 `RpgCosmetics`，以清洁重写方式实现少量可辨识、低开销的玩家共鸣外观。

| 检查项 | 旧项目现状 | 本服处理 |
|---|---|---|
| 版本耦合 | 为每个 CraftBukkit 版本维护 NMS 模块，最高到 `v1_21_R7`；没有 26.2 处理器 | 只使用 Paper 26.2 公共 `Player#spawnParticle` API，不使用 NMS 或数据包库 |
| 线程安全 | `EffectsTask` 每 tick 异步访问玩家状态与位置；`MovementCheck` 异步读取位置；GUI 动画异步修改界面；玩家初始化任务也会异步读取 Bukkit 对象 | 所有实体、世界、背包和粒子调用都留在主线程；没有每玩家任务 |
| 接收范围 | NMS 发送路径遍历同世界所有在线玩家，除可选过滤器外没有距离上限 | 每个发射者只选 24 格内最多 6 名可见接收者 |
| 负载上限 | 动态脚本、混合与静态效果没有现服统一的全局预算 | 光环、鞘翅轨迹和低频场景共用硬预算；正常每 5 tick 240 次发送、压力 64、严重状态 0 |
| 信息优先级 | 常驻装饰与战斗提示没有统一仲裁 | 受击或攻击后隐藏 8 秒，副本实例中隐藏，确保 Boss 地面预警、Action Bar、声音和标题优先 |
| 玩家偏好 | 支持选择效果、混合和颜色 | 接入 `/visuals`，用 `/aura` 选择光环，并在 `/trail` 独立组合轨迹形状与共鸣配色 |
| 许可 | 仓库根目录未发现 `LICENSE`、`COPYING` 或 `NOTICE` | 不复制源代码、配置或打包产物；若以后公开分发旧项目代码，应先由权利人补充明确许可证 |

## 实际吸收的设计

- 保留螺旋、环绕、脉冲、波纹、渐变双螺旋这五种直观轮廓。
- 几何计算拆成不依赖 Bukkit 的纯函数，并以点数预算为键在每次发射中复用结果。
- 玩家可自行选择外观；外观永远不提供伤害、属性、掉率或经济优势。
- `余烬螺旋`、`青芽脉冲`、`奥术星轨`、`潮汐回响` 默认可用；`幻彩共鸣` 需要账号绑定凭证永久解锁。
- 幻彩凭证既可作为累计支持纪念奖励，也可用 1600 星辉兑换，所以没有付费独占内容。
- 旧项目按站立、移动、潜行和鞘翅切换处理器的思想被收敛为两个有用状态：地面光环与真实滑翔轨迹；烟花推进使用 26.2 原生事件触发一次脉冲。
- `轻风尾迹` 免费，`共鸣双翼` 和 `星坠彗尾` 分别用 480/960 星辉永久解锁；形状与五种配色独立组合。

## 明确不迁移的内容

- 不迁移完整效果 DSL、任意脚本命令、玩家自由混合、静态世界特效编辑器和旧数据库。
- 不迁移 NMS 发送器、按版本复制的实现、ArmorEquipEvent、ACF 或旧 GUI 框架。
- 不让常驻外观承担技能判定、Boss 预警、NPC 指引或地图地标职责；这些继续由对应自研插件拥有。

这条边界既保留旧服务器的视觉识别度，也避免把 73 种效果全部常驻后造成客户端粒子淹没、网络放大和主线程竞争。
