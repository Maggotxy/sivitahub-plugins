# 核心玩法实装覆盖审计

更新时间：2026-08-12。范围仅为当前源码、配置和自动化测试；未把菜单文案、设计意图、旧运行包或配置上限当作实装证据。

## 结论

当前已经形成可运行的“选职业 -> 学技能 -> 动态野怪/原版活动 -> 六副本取核心 -> 族系共鸣锻造 -> 使用揭槽 -> 定槽精炼/突破”闭环，
并补上了血契、符箓两条稀缺隐藏路线。两条路线都有事务化资格、每路线 3 个全服名额、隐藏副本与技能书凭证以及在线副作用，
但尚未扩展成完整的隐藏职业技能树。三个隐藏副本分别发放 `ancient-echo`、`cinnabar-revelation`、`silent-thunder`；
六个 Boss、六种波次怪与三种血月怪共 15 套 BetterModel 已有运行映射。真正剩余的内容缺口是六关手工场景机关、
更多长期世界事件、高阶被动和经过多人周期验证的终局内容，而不是模型、隐藏路线或定槽精炼仍不存在。

原审计中“二转禁用、三转不存在”的缺口也已关闭：六职业各有两条二转承接路线和一条三转汇合路线，新增 18 个真实主动技；
启动图合同、技能目录合同和 JDBC 行锁共同拒绝跨职业、断链、错误前置及并发双选。当前源码合同成立，仍需真人、多人和异步故障验收。

| 技能书与借技 | 普通书有五本上限、唯一实例和幂等结算；三个隐藏关分别掉落 `ancient-echo`、`cinnabar-revelation`、`silent-thunder`，对应 1–3、2–4、3–5 点和不同最低等级，其中后两本的持久兑换记录分别是符箓、血契资格凭证。技能点可用于解锁节点或升级已学技能；升级同时锁定档案与技能行，预期等级使双击/旧菜单重放最多成功一次。六基础职业各有一个签名装备符文；全槽揭示并绑定本人后，可用 65% 强度、1.5 倍法力/CD 和 3 秒可见反噬跨职借用，已学同名技能则转为有界精通。 | 三本书目前都以技能点作为直接结算，只是数值、等级门槛和路线凭证语义不同；还没有独立可施放的隐藏技能书效果、技能品质重铸或高阶分支借技预算。 |
| 技能变异 | `SkillVariantCatalog` 是持久层、强化站和施放层共用的六职业白名单；治愈术/狂吼/影步/火球术/强力射击/临机应变分别实现逆转、铁誓、猎手印记、奥术迸流、裂弦、险境即兴。`/mutate <技能>` 先显示效果、代价、25% 概率和恢复规则，只有 `confirm` 扣款；成功后禁止无变化重铸，`restore` 清除持久化变异。 | 尚无技能变异重铸冷却和材料恢复路线；恢复目前销毁游戏金币。异步扣款/写入模糊提交和真人效果仍需故障注入。 |

| 血月与连猎 | 每七个原版夜晚、仅主世界自然怪；血魔、蚀月射手、裂隙行者三种稀有身份均有独立 BetterModel 映射、主动技、名称和额外材料，Lv.1–4 新人保护不会生成完整稀有外壳或主动技。连猎严格区分实体类型、幼年/成年、充能、尺寸，异类/动物、跨世界、远距传送和五分钟超时均重置，概率与保底有界。 | 整夜客户端、重启边界、拒绝资源包回退和高并发击杀仍未完成真人验收；世界长期事件仍主要只有血月与连猎。 |
| 六副本 | 远古遗迹/守秘层、硫泉深窟/朱砂心室、风暴秘库/静电核心都配置了真实体力、等级、1–4 人复核、两波守卫、Boss、阶段、时间限制、隐藏票、金币、功勋和独立材料/技能书。每条路线预热 1 个实例，合计 6 个热实例，世界硬上限 16；遗迹、硫泉、风暴各有两套族系地面机制。六个 Boss 与六种波次怪均有独立 BetterModel 源和运行映射。 | 竞技场几何仍共用，六关缺手工场景机关；还需排队退队、传送失败、硬崩、16 实例和多人真人注入，模型动画、碰撞及原版外壳降级也须客户端验证。 |

## 本次变更的自动化证据

- `SkillVariantCatalogTest`：六个技能/变异对严格白名单，拒绝跨技能组合。
- `SkillMutationRulesTest`：逐职业证明变异不会与原效果无代价叠加，并证明目标上限、单箭降幅、负面效果和独立视觉身份。
- `MutationConfigurationContractTest`：强化站必须恰好配置六种运行时变异，且重铸/恢复价格和成功率合法。
- `JdbcServicesTest` 定向用例：六种变异均可持久化，错误组合被拒绝，恢复会清空数据库与缓存中的变异。
- `LanguageBundleContractTest`：新增菜单、预览、效果与恢复文案中英文闭包。

已通过的定向命令：

```text
:plugins:rpg-api:test
:plugins:rpg-skills:test
:plugins:rpg-enhancement:test
:plugins:rpg-core:test --tests LanguageBundleContractTest
:plugins:rpg-core:test --tests JdbcServicesTest.skillLearningSpendsPersistentPointBudgetAndStoresVariant
:plugins:rpg-core:test --tests JdbcServicesTest.skillVariantPersistenceAcceptsEveryRuntimePairAndRejectsCrossSkillPairs
```

数据库 schema 与迁移清单当前均为 62 张 `rpg_*` 表，包含装备操作恢复、技能变异、隐藏路线、体力恢复、事故补偿审计、宠物成长与跨库复苏意图、晋升和社群回执；
清单合同会在两者不一致时失败关闭。既有自动化结果只证明当次源码模块合同，不替代真实 PostgreSQL 延迟、断连、模糊提交与 Paper 硬崩故障注入，
也不替代 30/50/70/100 人阶梯压测、多人真人完整验收和至少两周经济产销数据；当前没有证据证明单 Paper 已支持 100 人。
