# 商店闭环与原版可再生资源审计

更新日期：2026-08-08。审计范围包括 `RpgEconomy` 资源委托、功勋商店、双周商人，`RpgCommerce` 星辉/会员补给，`RpgMarket` 玩家市场，以及 `RpgCore` 金币/功勋/星辉兑换。

## 结论

原版中的“可再生”不是只指农作物。社区 Wiki 将自然/可生成生物掉落、钓鱼、生长、液体成石列为基础可再生来源，并把村民交易、猪灵交易、合成和熔炼列为复合来源；[铁傀儡农场](https://minecraft.wiki/w/Tutorial:Iron_Golem_farming)能按村庄生成机制持续生产铁锭，[怪物农场](https://minecraft.wiki/w/Tutorial:Mob_farm)则会集中生成并高效处理生物掉落。[村民交易](https://minecraft.wiki/w/Trading)每天可补货两次，还能把可再生的木材、作物等供应转换成绿宝石和其他商品。因此圆石、橡木、铁锭、小麦、红石、鳕鱼、怪物掉落和发酵蛛眼均不能单独成为金币凭证。参考：[Renewable resource](https://minecraft.wiki/w/Renewable_resource)、[List of renewable resources](https://minecraft.wiki/w/List_of_renewable_resources)、[Farming](https://minecraft.wiki/w/Farming)。

服务器现在使用“材料销毁 + 主动劳作证明”双条件。材料可以来自玩家自己的自动化建设，保留 Minecraft 工业化的价值；但库存本身不能铸币，金币产出取决于账号绑定、每日限量且有可靠事件来源的劳作证明。

商店按资金方向分成四类，不能互相替代：

| 入口 | 是否铸币 | 安全边界 |
|---|---:|---|
| 旅途补给 | 否 | 只销毁金币；五种应急日用品经过代码白名单审核，价格高于预期玩家市场，每账号数据库日限 |
| 资源委托 | 是 | 材料本身不计价；必须再消耗主动证明、满足累计游玩时间、每日轮换及数据库活动总额度 |
| 玩家市场 | 否 | 只把买家已有金币转给卖家并永久销毁 5%/10%；即使出现复制物，也不能从系统凭空产生金币 |
| 双周商人回收 | 是 | 只接收本期由同一商品发行的唯一发行号；同一发行号全服最多结算一次 |

因此不安装通用 `/sell`、箱子系统商店或无限库存 NPC 回收插件。普通玩家之间仍可以自由形成市场价格，但任何可再生原版物都没有“刷多少、系统就按固定单价收多少”的入口。

## 攻击面与现有封堵

| 攻击路径 | 封堵方式 |
|---|---|
| 刷石机无限圆石 | 委托还需劳作证明；每天轮换、单项一次、总计三次 |
| 树场、村民农场、自动小麦 | 作物/原木数量不产生劳作证明 |
| 铁傀儡农场、村民/猪灵交易 | 铁锭或交易结果本身不产生劳作证明 |
| 自动钓鱼与鳕鱼库存 | 一天最多从钓鱼获得一份证明；提交仍受单项和总次数限制 |
| 玩家放置矿后重挖 | 区块 PDC 记录放置坐标，跨重启并随活塞移动；精准采集和无经验矿不算天然矿脉 |
| 新建小号搬运共享库存 | 委托要求累计游玩 60 分钟、主动证明和独立日限；官网身份系统另将同网络多账号标记为 `REVIEW` |
| 补给商店买入再交系统 | 启动时从补给产物沿合成、熔炼、切石配方求闭包；能到达收购物时禁用对应委托 |
| 以后只改 YAML 加入廉价原木、纸、作物或铁 | 补给目录是代码审核白名单；商品 ID、材质、单次数量、日吞吐、价格底线或会员折扣任一越界都会停用 |
| 星辉商品、累计奖励或黑市货物经合成洗掉 metadata | 启动闭环扫描把所有系统发行物而非仅普通补给作为起点；可达收购物时禁用委托 |
| 合成/拆分改变数量 | 系统只删除无 metadata 的精确材料；启动检查覆盖配方可达性，不配置任意物品回收价 |
| 黑市用野怪/副本同材质掉落冒充 | 回收必须有 `rpgeconomy:black_market_offer=本期:商品ID`，并再次核对业务 marker |
| 复制一份本期黑市商品反复回收 | 每次发货写入唯一发行号；回购幂等键由发行号确定，同一发行号跨账号也只结算一次 |
| 功勋/星辉保护石卖给黑市 | 即使 `reward_marker` 相同，也缺少当期同商品来源；绑定商品还需 owner 一致 |
| 低价期囤货、高价期回收 | 只回收当前期货物；价格模型仍保留跨历史极值至少 10% 损耗的第二层保护 |
| 金币/功勋/星辉循环兑换 | 正价值向量证明每条边不增值；危险路线启动时禁用，且每条路线有数据库日/周限额 |
| 玩家市场左右手/漏斗/重放 | 玩家市场只转移已有金币并收 5%/10% 税；账号绑定边界、托管状态和幂等键独立校验 |
| 连点邮箱领取，或物品入包后数据库确认暂时失败 | 每名在线玩家只有一个领取流程；交付物带持久恢复标记并立即保存，确认前所有移动、丢弃、使用、放置、死亡掉落和漏斗路径均被取消；失败后只能以原标记续结 |
| 两个分片同时提交同一账号 | 劳作证明、来源额度、单项次数和总次数由数据库按“账号+日期”行锁串行化；20 路跨服务实例竞争测试只能成功三次 |
| 回档后重用已退款委托 UUID | 数据库不删除释放记录，而是保留 `RELEASED` 墓碑；同一 UUID 永久不能重新占用或结算 |
| `PREPARED` 凭据配空背包恢复 | 空背包不再被推断为已扣材料；未持久化到 `ESCROWED` 的凭据直接隔离，绝不自动发币 |

黑市回购只会从同一发行号的物品中凑齐一整组，不能把多个残缺发行混在一起结算。发行号同时进入持久化托管退款载荷；崩溃恢复仍使用原发行号，而复制品重放首笔结果时不会再次增加任何账号余额。

邮箱的单航班互斥是 Paper 节点内的第一层，数据库 `PENDING -> DELIVERED` 条件更新和背包恢复标记是第二层。当前拓扑要求代理层保证同一 UUID 同时只在一个 Paper 节点在线；未来允许跨节点重复会话前，必须再增加数据库领取租约/令牌并完成两节点故障注入，不能把 JVM 本地互斥误称为跨分片锁。

## 委托规则

- 每日按 `Asia/Shanghai` 轮换 3/7 项。
- 每项每账号每日 1 次，每账号总计 3 次。
- 账号累计游玩至少 60 分钟。
- 每次消耗 1 份劳作证明；每份证明允许的配置奖励不得高于 250 金币和 2 功勋。
- 劳作证明每日最多 4 份：天然经验矿最多 3、非配方进度最多 2、真实钓鱼最多 1、袭击最多 2；所有来源仍共享总上限。
- 证明不是货币或物品，不能丢弃、交易、放箱子或通过市场转移；权威状态只存在数据库，不依赖玩家存档/PDC。
- 授予、来源上限、证明总上限、单项/总提交次数在同一玩家日行锁下事务提交。证明占用使用与委托托管相同的 UUID；数据库失败并退款时标记为 `RELEASED`，成功后保留为 `ACTIVE`，崩溃恢复和跨分片重放不会重复消耗或重复发币。

`GATHERING` 的 1800 金币/12 功勋仍是数据库硬上限，位于上述门槛之后。它负责兜住未来配置误差，并不是自动农场安全性的唯一依据。

本次实际扫描曾发现“玻璃瓶补给 → 原版转换链 → 发酵蛛眼委托”，启动自检按规则停用了炼金委托。玻璃瓶是极易获得且不需要系统保底的物资，因此最终删除玻璃瓶补给，而不是为保留冗余商品放宽校验。

## 启动时拒绝规则

以下配置不会“带病运行”，对应商品或委托会被禁用并写入服务端错误日志：

- 任意系统发行物，或其合成、熔炼、烟熏、烧炼、营火和切石可达物，同时成为金币收购物；
- 普通补给不在代码审核的五商品目录内，或改换材质、压低价格、扩大日吞吐、会员折扣超过 5%；
- 重复收购同一种材料；
- 委托缺少证明成本、账号时长、总/单项日限；
- 委托每份证明奖励超过 250 金币或 2 功勋；
- 黑市使用未识别 marker、非正价格或无额度；
- 任一财富兑换边增加 `金币=1、功勋=600、星辉=1400` 的总参考价值。

## 调参边界

不要通过提高 NPC 回收价解决玩家“东西卖不掉”。可再生物过剩应由建造、锻造消耗、玩家市场和有证明门槛的资源销毁处理。若委托参与率过低，优先调整轮换构成、材料数量或引导；单次奖励每次最多调整 10%，观察完整七日的金币铸造/销毁比后再决定下一次变化。

当前五种系统补给只有火把、熟牛肉、箭、末影珍珠和烟花火箭。它们是缺货时的价格上限而不是获利入口；任何新增原版商品必须同时提交代码规则、转换闭包测试和经济用途说明，不能仅通过线上配置热加。
