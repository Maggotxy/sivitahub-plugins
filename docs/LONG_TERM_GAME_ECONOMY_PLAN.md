# 长期玩法 · 经济 · 赛季 总策划（v1 定版）

> 定位：**原版生存 × MMORPG 构筑 × 玩家经济 × 文明社区 × 软赛季历史**
> 约束：`docs/GAME_ECONOMY_CONSTITUTION.md` 为最高约束

## 1. 角色成长

- 四段式：0转 1-30 / 1转 31-60 / 2转 61-90 / 3转 91-120，`LOCAL_LEVEL_CAP=30, MAX_ASCENSION=3`
- 有效等级 `effective = asc*30 + local (1..30)`，战斗、掉落、副本门槛均以有效等级为准，显示与存储以本地等级为准
- 经验：阶段总预算 + 本地 1-29 归一化权重，不再 `effective^2 * stageMultiplier` 无限膨胀
- 技能点：本地里程碑发放（每 3 本地级 1 点跨段共享预算），晋升保留预算，数据库幂等补偿而非 `level/3` 重算
- 晋升：满本地 30 + 职业任务 + 装备评分 + 副本/功勋门槛，`AscensionService` 单事务内重查档案/分支/技能/副本/功勋

三转后不再增等级，只做横向构筑：变体、流派、图鉴、轮换词缀、竞速

## 2. 货币体系

| 货币 | 交易 | 来源 | 消耗 | 隔离 |
|---|---|---|---|---|
| gold | 是 | 狩猎/副本/委托/活动 | 锻造/精炼/突破/市场税/委托 | 流通 |
| merit | 否 | 副本/精英/活动 | 晋升/保护石/商店 | 账号绑定 |
| starlight | 否 | gold+merit凝聚 / 活动 / OP审计发放 | 绑定辅助物/外观/会员 | 账号绑定 |
| support_credit | 否 | 现实付费验签订单 | 仅外观/便利，不触及战力经济 | **独立账本，C-012** |

禁止：无限等级、固定价无限回购、充值影响战力/经济、全服删档续命、每玩法一货币、低概率冒充深度

## 3. 装备生命周期（12态）

`CREATED → BOUND → UNBOUND → LISTED → SOLD → SALVAGED → SACRIFICED → LEGACY_EXTRACTED → SEASON_ATTUNED → DESTROYED → QUARANTINED → RESTORED`

- 胚材 0-4 决定基础强度与槽上限扩展，不保证结果
- 绑定：首次战斗/精炼/突破即绑定；` /unbind` 动态金币回收后可流通，锻造者永久保留
- 退出四层：①分解/传承 ②高阶突破献祭 ③新赛季调谐 ④市场成熟后评估极小比例税收支持的浮动销毁（需 RFC）

## 4. 玩家市场

- 单一托管结算，`item_id` 唯一索引，`PREPARED/ACTIVE` 互斥，买单与制作订单共用账本
- 普通物资 5%，自制装备 10%，168h过期，分页+确认页，明示手续费
- 实体摊位仅为托管入口，不自持库存/余额

## 5. 软赛季

分层：`永久资产层（金币/外观/图鉴/锻造者） / 赛季资产层（赛季功勋/凭证/核心） / 短周期层（日/周委托）`

换季经 `SeasonSettlementService` 事务机，含预览、冻结、结算、校验、回滚。章节推进 ≠ 赛季结算。

成熟期目标（示例，真实阈值见 yaml）：
- 活跃金币周增长 0%–1.5%
- 7日 Sink/Faucet 0.90–1.05
- 转换释放金币占比 <10%
- 高价值装备 创建/退出 0.90–1.20
- 市场挂牌 P90 <96h

## 6. 社群治理与文明

角色：`LEADER / DEPUTY / TREASURER / BUILDER / EVENT_HOST / RECRUITER / MEMBER`
- 双人审批、大额双签、会长继任、解散冷静期、公共仓库审计
- 城市工程：全服共同项目，世界归档，赛季历史陈列
- 社群不提供独占攻击/掉率/经验/装备上限

## 7. 内容管线与经济调参

- 内容：手工模板 + 程序化预热池，轮换词缀，图鉴驱动
- 指标：活跃金币、Sink/Faucet、库存龄、最大来源占比、P90
- 调参：单次 ≤10%，观察 ≥7d，自动系统仅冻结

## 8. 反作弊与事故

- 冻结异常来源，审计可回放
- 复制/误发：隔离 → 取证 → 事务冲正/补偿（引用原流水），禁止全服回档

## 9. 正版 UUID 与多服

- 正版迁移：离线 UUID → 正版 UUID 幂等映射，邮箱/市场租约跟随
- Velocity：Session Lease + 邮箱租约 + Outbox + Advisory Lock
