### 新增到 skill 的踩坑（全部实测）
- `git push` 挂死的真根因是 `credential-helper-selector`，修法 `git -c credential.helper= -c credential.helper-selector.enabled=false push`
- 往空仓库推第一个分支会挂：先推极小 commit 建 main，再 `--force` 推全量
- `list_branches` / `list_pulls` 默认只返 10 条，必须显式分页
- PR 号是**字符串**；合入前先看 `mergeable_state`
- 合入 API 必须带 `commit_title`
- 同文件冲突的正确处理：派 NPC 在**已存在的分支**上 `git merge origin/main` 并保留双方语义（实测 3 个 13 分钟解决）
- `eclipse-temurin:25-jdk` 里 curl/python3/wget/sha256sum 全缺
- CNB 出网**间歇性**（同一次运行 6/7 个 jar 成功、1 个 read timeout）⇒ 所有联网步骤都要自带重试
- 编译期依赖必须与运行时 jar **完全同版本**；拿不到就 vendor 入库，不要用近似版本
- 编排器是**层级同步**的，且实测两次卡在层级边界（分支/PR 已全部就绪但进程不前进）⇒ 看分支+PR 数比看日志准
